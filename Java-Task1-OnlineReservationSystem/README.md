# Online Reservation System

**Oasis Infobyte — Java Development Internship | Task 1**

## Project Overview
A Java-based railway reservation application with a graphical user interface for booking tickets and managing reservations.

## Technologies Used
- Java
- Java Swing
- JDBC
- SQLite
- Maven

## Features
- User login
- Train selection
- Ticket reservation
- Automatic PNR generation
- Reservation lookup
- Ticket cancellation
- Database-backed reservation storage

## Project Structure
- `src/` — Java source code
- `config/` — Application configuration
- `database/` — Database-related resources
- `screenshots/` — Project screenshots
- `pom.xml` — Maven configuration

## How to Run
1. Install a compatible JDK.
2. Open the project in IntelliJ IDEA.
3. Load the Maven project and dependencies.
4. Run the application's main Java class.
